# SAINTYVES Beat Store

Static HTML/CSS/JavaScript website ready for Vercel, Netlify or GitHub Pages.

## Files
- `index.html` — homepage
- `beats.html` — full catalog
- `beat.html` — beat details + licensing
- `admin.html` — demo admin dashboard
- `style.css` — complete styling
- `script.js` — catalog, search, cart and demo admin interactions

## Later production connections
Replace the demo pieces with:
- Paystack / Stripe / Flutterwave checkout
- Supabase / Firebase / another database
- Real admin authentication
- Cloud audio/artwork storage
- Automatic beat delivery after payment
- Real contact/social links
- Custom domain

The current admin/catalog data uses browser localStorage so the demo works without a backend.
